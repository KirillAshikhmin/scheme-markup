# Доработка чертёжного шрифта

Здесь лежит то, чем собран `src/assets/gost-type-a.ttf`. В сборку страницы
ничего отсюда не попадает — скрипт запускается руками, когда шрифт нужно
пересобрать.

## Что и зачем

Исходный `gost-type-a-source.ttf` — шрифт, который дал заказчик. В нём
260 знаков, и для чертежа их не хватает: нет длинного и среднего тире,
градуса, диаметра и пустого множества.

Хуже того, шрифт собран под однобайтовую кодировку: коды 0xC0–0xFF отданы
кириллице по CP1251, все 64 из 64. На практике это значит, что набранный
знак умножения `×` (U+00D7) рисовался буквой «Ч», а `Ø` (U+00D8) — буквой
«Ш». Молча, без подмены шрифта, потому что для браузера знак в шрифте есть.
Это опаснее отсутствующего знака: отсутствующий видно сразу, подменённый
уезжает в чертёж и в печать.

`draw-glyphs.py` добавляет недостающие знаки и чинит эти два.

## Почему знаки нарисованы, а не взяты из другого шрифта

Первым заходом знаки переносились из `osifont` — свободного чертёжного
шрифта, где есть всё. От этого отказались по двум причинам.

Первая: заказчик посмотрел образец и сказал, что начертания «похожи, но
разные». Так и есть — osifont шире и крупнее, его знаки в строке видно.

Вторая: в исходном шрифте записано
`Copyright © 1996-97. ASCON Ltd. All Rights Reserved.`, а osifont лежит под
GPL. Файл шрифта публикуется вместе со страницей и скачивается, то есть
распространяется. Смешать в нём глифы из этих двух источников — нарушить
сразу обе лицензии.

Поэтому знаки строятся из размеров самого шрифта: толщина штриха берётся у
дефиса, высота заглавной — у цифры, перечёркнутый круг — из кольца буквы
«О». Начертание получается не «похожее», а его собственное, и ничего чужого
в файле нет.

**Про лицензию исходного шрифта решения не принято.** «All Rights Reserved»
означает, что права у АСКОН, и публикация файла вместе со страницей — вопрос
к правообладателю. Это записано здесь, чтобы не потерялось.

## Как пересобрать

```
python3 -m venv /tmp/fontenv && /tmp/fontenv/bin/pip install fonttools
/tmp/fontenv/bin/python tools/draw-glyphs.py \
    tools/gost-type-a-source.ttf src/assets/gost-type-a.ttf
```

`fonttools` нужен только здесь и в зависимости проекта не входит — у
страницы их по-прежнему нет.

## Что проверить после пересборки

1. **Ни один прежний знак не изменился.** Сверка контуров и ширин всех 260
   кодов исходного шрифта; меняться имеют право ровно два — `×` и `Ø`.
   Буквы «Ч», «Ш», «ч», «ш» по своим кириллическим кодам обязаны остаться
   теми же: их глифы никуда не делись, переназначены только латинские коды.
2. **Браузер принимает файл.** Проверяльщик шрифтов в Chrome молча
   отказывается от файла с несогласованными таблицами, и на странице просто
   нет шрифта. Открыть `dist/index.html` и посмотреть на подписи.
3. **Новые знаки стоят по месту** — градус на высоте заглавной, тире на
   высоте дефиса, крест по середине цифры.

## Ловушка, которая осталась

Коды 0xC0–0xFF, кроме двух починенных, по-прежнему ведут на кириллицу.
Набранное `À` нарисуется буквой «А». Чинить это переносом всей латиницы с
диакритикой не стали — она в чертеже не нужна, а каждый перенесённый глиф
это чужое начертание в файле. Вместо этого в сборке есть тест, который
проходит по словарю строк и кодам типов и падает, если такой знак туда
попал.
