# scheme_image — вход для Claude Code

Claude Code сам читает `CLAUDE.md`, а не `AGENTS.md`, поэтому этот файл — точка входа. Ниже подключена карта архитектуры. Остальное читать по мере надобности:

- **правила и ловушки** — корневой `../AGENTS.md`, раздел «Разметка электроточек на схемах (`scheme_image/`)», подразделы «Правила, которые нельзя нарушить» и «Ловушки». Прочитать при первой правке кода за сессию;
- **что умеет сервис, `tools/scheme.mjs`, живой прогон** — `AGENTS.md` рядом;
- **что открыто и что договорено с заказчиком** — `../.autopilot/PROGRESS.md`. Правка без автопилота дописывается туда строкой в «Правки без автопилота».

## Коротко о главном

- **G68: готовый объект не ломается.** Правка формата — только с миграцией и тестом на старом файле. Догадку показывают, а не применяют.
- **Ни одной зависимости.** Только именованные экспорты; имена верхнего уровня уникальны во всём `src/`; циклов нет.
- **Объект правит только `model.js`, отмену пишет только `canvasCommit`.** Живое состояние имитации в объект не идёт.
- **Строки — только `src/strings.js`.**
- **`dist/` лежит в git:** после правки `src/` выполнить `node build.js` и закоммитить `dist/` вместе с исходниками.
- **CSS тестами не проверяется** — открыть страницу глазами.
- **`tmp/` — настоящие объекты заказчика:** не коммитить, имена помещений в отчётах не называть.
- **Коммиты** — Conventional Commits по-русски: `feat(scheme-markup): …`, `fix(scheme-markup): …`. Коммитить явными путями: в репозитории параллельно работают другие окна.
- **После готовой правки — выкладка на прод** (§10 карты), только быстрой перемоткой.
