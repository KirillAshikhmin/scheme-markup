# 029. D03: дверь миграции принимают обе трубы, живьём её передаёт только «Разметка»

Статус: принято · 2026-11-08

## Контекст

План: перевод старого объекта на ссылку (ADR 026) идёт в обе трубы открытия,
из файла и из базы, и в обеих у двери есть тест на старом объекте.

## Решение

Код доказал: дверь принимают обе трубы, но реестр, нужный для узнавания, живьём
подаёт только «Разметка». Страница просмотра объект не переписывает вовсе, а
реестр лежит за сетью.

## Почему

- **Просмотр ходит в реестр сам, чтобы переводить** — отвергнуто: просмотр
  только читает (ADR 024), а перевод — запись.
- **Не давать дверь второй трубе** — отвергнуто: обе трубы должны вести себя
  одинаково, иначе одна из них первой сломает старый объект.

## Последствия

- Старый объект в просмотре остаётся с исходником текстом; ссылка его не
  укорачивает, пока «Разметка» не открыла и не перевела его.
- Живой путь второй трубы закрыт только тестами.
