# 028. D02: у манифеста просмотра область общая

Статус: принято · 2026-11-08

## Контекст

План предполагал: у страницы просмотра свой манифест установки, и область
действия сужается до неё, чтобы значок вёл только в просмотр.

## Решение

Код при сборке первого таска доказал, что сужать нельзя. Манифест просмотра
собственный (имя, начальный адрес, значки), но область остаётся общей.

## Почему

- **Узкая область** — отвергнута: адреса вне неё, включая сам файл
  офлайн-обработчика, выпали бы из приложения. Значок всё равно ведёт в
  просмотр по начальному адресу, область для этого не нужна.

## Последствия

- Установленное приложение просмотра технически может перейти на «Разметку» по
  ссылке; запретить это область не помогает.
- Отдельный манифест нужен и проверяется как локальная ссылка при сборке.
