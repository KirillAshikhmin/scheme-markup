# 024. «Только для чтения» — род страницы и белый список умений

Статус: принято · 2026-11-08

## Контекст

В «Разметке» каждая кнопка и панель уже спрашивает, разрешено ли ей умение в
текущей раскладке. Страница просмотра (ADR 023) несёт тот же код, но правки на
ней быть не должно вовсе. Девять умений никто не спрашивал.

## Решение

Страница знает свой род: правка или просмотр, читается один раз при старте из
разметки. Одна дверь отвечает «можно ли умение»: раскладка плюс род страницы,
для просмотра — белый список. Все прежние вопросы к раскладке идут через неё.

## Почему

- **Второе условие «и не просмотр» в каждой кнопке** — отвергнуто: мест десятки,
  новая кнопка по умолчанию правила бы объект, и забыть условие можно молча.
- **Белый список вместо чёрного** — новое умение в просмотре запрещено, пока его
  не разрешили; ошибка выглядит как пропавшая кнопка, а не как правка объекта.
- **Спрятать правку стилями** — отвергнуто: заказчик не должен мочь править, а
  не просто не видеть.

## Последствия

- Девять умений, о которых раньше не спрашивали (список объектов, таблицы,
  выгрузки, открытие файла и другие), теперь приходится спрашивать — это была
  основная работа.
- Новое умение обязано попасть в таблицу «умение × род × раскладка»; без записи
  в просмотре его нет.
- Правило держится на дисциплине вопроса: код, не спросивший дверь, ограничения
  обойдёт.
