# 009. Движок имитации живёт в Worker и единственный хозяин состояния дома

Статус: принято · 2026-10-23

## Контекст

Логические сценарии Sprut.Hub — чужой JavaScript, и API хаба синхронный:
`Hub.getCharacteristicValue` возвращает значение сразу. Такой код может
зависнуть (`while(true)`), а страница при этом не должна встать. В кодовой базе
Worker до сих пор не было.

## Решение

Весь движок имитации — состояние дома, события, таймеры, интерпретатор блоков,
эмуляция API хаба — исполняется в Worker. Он единственный хозяин состояния.
Страница держит зеркало: действия человека уходят сообщением, обратно приходят
пачки изменений. Движок состоит из чистых модулей без DOM, поэтому те же модули
тестируются в Node без Worker.

Живое состояние никогда не идёт через `canvasCommit` и `project`: любая смена
`project` — шаг истории, `updatedAt` и автосохранение. Всё, что лежит в файле
(профили, аксессуары, сценарии, привязки), наоборот, пишется только через
`canvasCommit`.

## Почему

- **Скрипты в Worker, состояние на странице** — отвергнуто. Синхронный
  `getCharacteristicValue` внутри потока не может спросить страницу и дождаться
  ответа; пришлось бы держать копию состояния в потоке, и два хозяина разошлись
  бы.
- **Всё на странице, без Worker** — отвергнуто как основной путь: зависший
  сценарий вешает страницу целиком. Остался запасным путём на случай, когда
  Worker недоступен.
- **Состояние в `project`, чтобы хранилось само** — отвергнуто: засоряет историю
  отмены, будит автосохранение и слияние папки с напарником на каждый щелчок по
  выключателю.

## Последствия

- Любое действие человека и любое изменение приходит на экран с задержкой
  сообщения; экран показывает зеркало, а не правду.
- Движок и всё, что он тянет, не смеет касаться DOM; бандл потока проверяет
  сборка. Он тянет весь `strings.js`, поэтому страница выросла примерно на
  650 КБ.
- Перезапуск потока (сторож, ADR 010) восстанавливает состояние из зеркала, а
  задержки и таймеры теряются: перезагрузка хаба их тоже не переживает.
- Правка объекта во время имитации перестраивает дом и снимает таймеры
  сценариев — об этом пишется в журнал.
- Запасной путь без Worker исполняет чужой код в странице без защиты от
  зависания; журнал и полоса имитации обязаны это говорить.
