# 023. Две страницы — один бандл: просмотр отличается разметкой, а не составом

Статус: принято · 2026-11-08

## Контекст

Заказчику нужна вторая страница, только для чтения (ADR 024). Сборка кладёт в
бандл каждый файл `src/**/*.js`: списка включения нет. Панель монтируется лишь
при наличии своего узла в разметке, отсутствующий узел молча пропускается.

## Решение

Страница просмотра — второй шаблон разметки (`view.html`) того же бандла, с теми
же кодом и стилями. В нём есть только те точки монтирования, которые нужны
просмотру. Собирается тем же путём, что главная, и проходит те же проверки.

## Почему

- **Второй бандл другого состава** — отвергнут: дешевле для телефона, но нужен
  список включения, которого у сборки нет, и проверки на каждый состав. Цена
  выше, чем вес страницы.
- **Выкинуть лишнее tree-shaking'ом** — отвергнуто: сборка склеивает модули в
  один IIFE без анализа использования, а вводить для этого сборщик значит снять
  правило «ни одной зависимости» ради выигрыша, который никто не требовал.
- **Класть вторую страницу «как есть», как памятку** — отвергнуто: ей нужны
  стили и код внутри, а памятка их не несёт.

## Последствия

- Страница заказчика весит столько же, сколько «Разметка»: 2,9 МБ, по сети около
  0,67 МБ сжатой. Для телефона это неприятно, и это цена решения.
- Любой новый модуль попадает в обе страницы, нужен он просмотру или нет.
- Просмотр не «урезанная копия»: что скрыто, держит разметка и перечень умений
  (ADR 024), а не отсутствие кода.
